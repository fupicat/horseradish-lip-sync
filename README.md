# Horseradish lipsync

Ainda estou trabalhando nisso então vou escrever um README melhor depois! Por enquanto, você pode baixar a versão pré-compilada, renomear para "rhubarb.exe" e tentar substituir qualquer instalação do rhubarb lip sync por ele. O horseradish é compatível com os argumentos e os formatos de saída do rhubarb. Não posso garantir que é 100% compatível com todos os apps que usam ele, estou testando ainda.

## Compilar (Windows)

1. Baixe e instale o miniforge.
2. Crie um ambiente de acordo com o arquivo `requirements.txt`.
3. Baixe o arquivo `sqlite-tools-win-x64.zip` no site do [sqlite](https://sqlite.org/download.html), e extraia o arquivo `sqlite3.exe` para dentro desta pasta.
4. Rode o arquivo `build.bat`.
